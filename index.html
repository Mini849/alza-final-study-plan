Skúška Postup na papieri

Najprv premenné, potom cyklus, potom update, potom test na malom príklade. Pri code readingu vždy tabuľka.

Metóda

Postup pre každý pseudokód

Toto je pevný rámec. Ak sa zasekneš, nečakaj na inšpiráciu; prejdi kroky v poradí.

1. Vstup a výstup

Napíš, čo algoritmus dostane a čo má vrátiť: číslo, pole, reťazec, boolean, index alebo počet.

2. Stavové premenné

Vyber minimum premenných: `pocet`, `sucet`, `najmensie`, `najdene`, `lavy`, `pravy`, `temp`.

3. Správny cyklus

Lineárny scan ide od `0` po `n - 1`. Porovnanie susedov ide iba po `n - 2`. Reverse ide po polovicu.

4. Jedna hlavná podmienka

Podmienka mení stav: pripočíta, prepíše maximum, nastaví `false`, alebo spraví `swap`.

5. Mini test

Skús vstup s 3-5 hodnotami. Odhalí zlé hranice cyklu, nulovú inicializáciu produktu a zabudnutý return.

6. Zákaz skratiek

Nepouži `.sort()`, `reverse()`, `max()`, `min()` ani hotové knižničné funkcie. Skúška chce samotný algoritmus.

Code reading cez trace tabuľky

Pri čítaní kódu nehádaj výsledok. Body sú za disciplinované sledovanie premenných krok po kroku.

Stĺpce tabuľky

`krok`, `i`, `j`, `podmienka`, `výpočet`, `nová hodnota`. Pri `while` nahraď `i/j` premennými z kódu.

Poradie

Najprv over podmienku cyklu, potom vykonaj telo, potom aktualizuj premenné. Nepreskakuj poslednú neúspešnú podmienku.

5 % štúdia

Rýchly praktický ťahák

Krátke vety, ktoré stačia ako opora pri vysvetlení algoritmu alebo pri kontrole zložitosti.

Big-O

Opisuje, ako rastie počet krokov alebo pamäte pri raste vstupu `n`.

Lineárny scan

Prejde prvky jeden po druhom. Typicky `O(n)`.

Bubble sort

Porovnáva susedov a väčšie hodnoty posúva ku koncu. Typicky `O(n²)`.

Binárne vyhľadávanie

Funguje iba v zoradenom poli a delí interval na polovice. `O(log n)`.

Stack

LIFO: posledný vložený prvok ide von prvý. Operácie `push`, `pop`.

Queue

FIFO: prvý vložený prvok ide von prvý. Operácie `enqueue`, `dequeue`.

Kontrola pred odovzdaním

Chyby, ktoré berú body

Po dopísaní riešenia prebehni tento zoznam. Väčšina praktických strát vzniká z detailov, nie z nepochopenia zadania.

`sucin = 0`

Produkt alebo faktoriál musí začínať na `1`, inak celý výsledok ostane nula.

Zlé hranice

Pri susedoch nekontroluj `pole[n]`. Posledné porovnanie je `pole[n - 2]` s `pole[n - 1]`.

Swap bez `temp`

Ak prepíšeš prvú hodnotu bez dočasnej premennej, jednu hodnotu stratíš.

Hotové funkcie

`sort`, `reverse`, `max`, `min` a podobné skratky nepíš. Skúša sa algoritmus.

Druhé maximum

Sleduj dve hodnoty naraz a rozhodni, čo robiť s duplicitami podľa zadania.

Palindrome

Netreba otočiť celý text. Stačí porovnávať ľavý a pravý znak smerom do stredu.

Code reading spamäti

Bez tabuľky ľahko preskočíš update po poslednej iterácii.

Chýbajúci return

Každý algoritmus musí jasne vrátiť alebo vypísať výsledok.
